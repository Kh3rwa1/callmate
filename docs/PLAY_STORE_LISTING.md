# Google Play store listing – CallPilot (`com.callpilot.app`)

Copy for the Play Console main store listing in English (default), Hindi
(`hi-IN`) and Bengali (`bn-IN`). Limits: title ≤ 30, short description ≤ 80,
full description ≤ 4000 characters (Play counts characters, not bytes). The
counts below were checked with a script; re-check after any edit.

Policy notes before publishing:
- No prices, ranking words ("best", "#1", "top"), emoji-only lines or calls to
  action like "download now" in the title or short description (Play metadata
  policy). Prices change: keep them out of the listing, the app and the `/get`
  page show the live plan catalogue.
- Claims must match the shipped app. The listing says the AI introduces itself
  as an AI and that calls are recorded: **confirm the live Sarvam agent's
  opening line does this before publishing** (see the TODO in
  `backend/src/routes/legal.ts`).
- Privacy policy URL: `https://<api domain>/legal/privacy`. Account deletion URL:
  `https://<api domain>/legal/delete-account`.
- Marketing/referral links for ads and WhatsApp: `https://<api domain>/get` (adds
  the Play install referrer; see `API.md` → Public pages).
